# Transaction Analytics Dashboard

## Project Overview

This project is an Excel-based Transaction Analytics Dashboard developed to analyze customer spending behavior, transaction patterns, card usage, expense categories, and revenue performance.

The dashboard transforms raw transaction data into meaningful business insights using Microsoft Excel and Power Query for data cleaning, transformation, analysis, and visualization.


# Objectives

- Analyze overall transaction performance and revenue contribution.
- Identify top-performing cities based on transaction value.
- Evaluate customer spending patterns by gender.
- Compare transaction volume across card types.
- Analyze spending behavior across expense categories.
- Generate recommendations to improve customer engagement and revenue growth.

# Key Insights

1. Greater Mumbai generated the highest transaction value, making it the strongest revenue-contributing city.

2. Female customers recorded higher average spending per transaction compared to male customers.

3. Bills generated the highest spending amount, while travel recorded the lowest contribution.

4. Silver cards recorded the highest transaction volume, showing strong customer preference.

5. Transaction patterns varied across quarters, highlighting seasonal spending behavior.


# Recommendations

1. Increase premium offers in Greater Mumbai to maximize revenue opportunities.

2. Create targeted campaigns for high-value customer segments.

3. Introduce incentives to improve spending in lower-performing categories.

4. Expand Silver card benefits while encouraging customers to explore premium card options.

5. Apply successful strategies from high-performing cities across other locations.
